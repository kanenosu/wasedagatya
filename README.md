# 早稲田ガチャ

https://kanenosu.github.io/wasedagatya/

早稲田大学の4年間を生きるブラウザゲーム。学部も入試方式も実家の太さもガチャで決まり、日付が自動で進み、選択イベントで止まる。

- 実在の必修科目で履修し、成績はMyWaseda風の全画面で1科目ずつ発表
- 界隈系サークル（ザ・ワセダ・ガーディアン、早稲田精神昂揚会、運スタ、早慶戦支援会、企画集団便利舎、鵬志会など）は自分で選べる
- 行動方針、ゲージ不足で選べない選択肢、借金・入院・停学などの危機イベント

`index.html` 1ファイルで動く。ローカルではブラウザで開くだけで遊べる。

## 注意
サークル名や店名、行事は実在のものを使っているが、出来事や性格づけは脚色。確率や停学の期間などはゲーム用の設定で、実際の規程ではない。20歳未満の飲酒・喫煙は法律で禁止されている。
