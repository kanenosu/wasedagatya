# 早稲田ガチャ

https://kanenosu.github.io/wasedagatya/

早稲田大学の4年間を生きるブラウザゲーム。学部も入試方式も実家の太さもガチャで決まり、日付が自動で進み、選択イベントで止まる。

## 遊び方
`index.html` をブラウザで開くだけで動く。ビルドは不要。

## ファイル構成

## イベントの書き方
選択イベントは次の形。`random.js` の `POOL` に足せばランダムで出る。

```js
{w:2,terms:[0,7],when:s=>!!s.circle,title:"タイトル",text:"本文",
 choices:[
  {label:"選択肢",req:{kane:5},chance:s=>pc(s.s.jin,45),
   ok:{t:"成功したときの文",d:{jin:5,kane:-5}},
   ng:{t:"失敗したときの文",d:{men:-5}}},
 ]}
```

- `w` 出やすさ、`terms` 出る学期（0=1年春 … 7=4年秋）、`when` 出る条件
- `req` 選ぶのに必要なゲージ（足りないと押せない）、`chance` 成功率
- `d` ステータスの変化（`gaku` 学力、`jin` 人脈、`tai` 体力、`men` メンタル、`gk` ガクチカ、`kane` 所持金（万円））

勝手に流れる出来事は `flow.js` などの配列に `{m:[月],c:条件,t:"文",d:{変化}}` を足す。

## Claudeのアーティファクト用に1ファイルにまとめる
```
python3 tools/bundle.py 出力先.html
```

## 注意
サークル名や店名、行事は実在のものを使っているが、出来事や性格づけは脚色。特定のサークルや個人を誹謗中傷する意図はない。確率や停学の期間などはゲーム用の設定で、実際の規程ではない。20歳未満の飲酒・喫煙は法律で禁止されている。
